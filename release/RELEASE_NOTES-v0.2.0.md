# 发布说明 · v0.2.0

**发布日期**：2026-10-28　**tag**：`v0.2.0`　**渠道**：GitHub Releases（不发 PyPI · ADR-008）

**这一版加了什么**：**图形版**——**双击一个 exe 就有一个真正的图形窗口**（tkinter），
带**主菜单**（选玩法 · 选难度）。**内核、规则集、契约、事件基线一个字节都没改**
（M6 的 `G6-1`）。

## 产物

| 文件 | 说明 |
| --- | --- |
| `tetris-graphics.exe` | **图形版（新版主角）**：双击 → 主菜单 → 选玩法与难度 → 开打 |
| `tetris-cli.exe` | 控制台版：跑 `sim` / `replay` / `inspect` / `systems` / `variants` / `play` |
| `tetris-play.exe` | 终端双击即玩版：开一个控制台窗口直接进游戏 |
| `tetris_kernel-0.2.0.tar.gz` | 源码分发包（sdist） |
| `tetris_kernel-0.2.0-py3-none-any.whl` | Python 包（wheel） |
| `SHA256SUMS.txt` | 各附件的 SHA-256 |

**运行环境**：Windows x64；exe 免安装（含 Python 运行时与 Tcl/Tk）。

## 用法

```
# 双击 tetris-graphics.exe
#   → 主菜单：玩法（标准玩法 / 重力旋转 / 落地生长）× 难度（起始等级 1 / 5 / 10）
#   → 开局。键盘：← → 移动 · ↑ / Z / X 旋转 · ↓ 软降 · 空格 硬降 · C 暂存 · P 暂停 · Q 退出
#
# 图形版也有命令行入口：
tetris graphics --seed 20261120
# 自检（开真窗口跑 30 帧就退，退出码 0 = 通过）：
tetris-graphics.exe --selftest
```

## 这一版的核心口径

- **图形层是快照驱动的**：画面的一切来自内核的只读快照，**渲染器没有自己的规则**。
- **手感没有分叉**：图形输入只做「键名翻译」，**DAS / ARR 与命令翻译整套复用**既有的键盘适配器——**同一个种子 + 同一串按键，图形版与终端版逐帧指纹全等**（M6 的 `G6-5`）。
- **难度 = 起始等级**，用既有的 `setLevel` 命令落地——**没有新增任何命令**。
- **内核 / 规则集 / 契约 / 事件基线全程零变化**（`G6-1`）。

## 已知边界

- **性能**：`G5-2` 未达标——多局合并样本下 AI 决策 P99 为 1481 μs，门槛是 400 μs。AI 已不再是逻辑帧的越界者，剩余开销在变体与实时宿主档自身。见 `PROGRESS.md`。
- **图形版没有录像回放界面**：`replay` 仍是终端命令。
- **难度只改起始等级**，不改 DAS / ARR 手感参数。
- **Windows only**：平台范围只覆盖 Windows x64。

## 与 v0.1.0 的关系

**并存**：v0.1.0 是**终端版**（内核底座 + 变体 + AI + 录像回放），v0.2.0 在它之上
**加了图形外壳**。v0.1.0 的附件仍可下载。
