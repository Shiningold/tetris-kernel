# AI 决策日志

记 LLM 写代码过程中的取舍：时间 · 涉及的模块 · 发生了什么 · 为什么这么写 · 被否掉的方案。

**一周一个文件**，文件名 `YYMMWW.md`（两位年 + 两位月 + 两位周次）。

- 周的归属按**周一所在的月**算：周一落在 10 月，这一周就算 10 月的周。
- 周次在月内从 1 数：某月**第一个周一落在该月**的那一周，是该月第 1 周。
- 例：`261003.md` = 2026 年 10 月第 3 周（该周周一是 2026-10-19）。

**规则以 `../AGENTS.md` 的「AI 决策日志」一节为准**；本文件只说明格式。日志只追加，不改写已有条目。
