一帧内的事件流时序 60fps · 固定步长

[输入适配器] 收到按键
   └─ 派发 command moveLeft
[内核] 校验通过 ──▶ command:accepted
[内核] 移动活动方块
   ├─▶ piece:moved
   └─▶ state:changed ──▶ [渲染器] 仅标记脏
[宿主] 推进一帧 ── 派发 command tick
[内核] ──▶ clock:tick
   ├─▶ [指标] 累加帧数
   ├─▶ [输入] 长按检测 ── 自动重复 ──▶ 入队
   └─▶ [AI]  计算落点 ── 派发命令 ──▶ 入队
[内核] 本轮分发结束 ──▶ 取出队列（FIFO）
   └─▶ 逐条执行 ──▶ 新事件 ──▶ 第 2 轮分发（订阅者看到的仍是同一份状态）
   └─▶ 队列空 / 达轮次上限 ── 结束本帧命令处理
[内核] 重力下落 ──▶ clock:gravity
[内核] 触底 ──▶ piece:lock-delay-start
[内核] 延迟到期 ──▶ piece:locked
   ├─▶ board:changed
   ├─▶ board:lines-cleared
   │     └─▶ score:changed ──▶ [成就] ──▶ achievement
   └─▶ piece:spawned ──▶ state:changed
[渲染器] 帧末拉取一次快照 ──▶ 重绘（高频事件不触发拉取）
[日志] 订阅 '*' ── 每一步均产生结构化日志
[回放] 订阅 command:accepted（含 AI 命令） ── 形成可重放录像；回放期间命令源独占

技术栈 本阶段不做选型

内核不得依赖任何特定语言运行时、图形接口或系统能力。
渲染、输入、存储、网络均按「适配器」契约接入，可整体替换。
契约稳定后再评估实现选型。
